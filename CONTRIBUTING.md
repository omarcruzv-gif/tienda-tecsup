# Guía de contribución

Gracias por tu interés en colaborar con el proyecto Tienda TECSUP.

Esta guía establece las pautas para reportar errores, proponer mejoras y enviar cambios al proyecto.

## 1. Reportar errores (Bugs)

Si encuentras un error en la aplicación, puedes reportarlo mediante la sección Issues del repositorio.

Al crear un reporte, incluye:

* Una descripción clara del problema.
* Los pasos necesarios para reproducirlo.
* El resultado esperado.
* El resultado obtenido.
* Capturas de pantalla, si son necesarias.

## 2. Proponer mejoras

Si tienes una idea para mejorar el proyecto, puedes crear un Issue describiendo:

* La funcionalidad que deseas agregar.
* El problema que busca resolver.
* Los beneficios que aportaría al proyecto.

Las propuestas serán revisadas antes de su implementación.

## 3. Enviar un Pull Request

Para contribuir con cambios en el código:

1. Crea una rama para tu modificación.
2. Realiza los cambios necesarios.
3. Comprueba que la aplicación siga funcionando correctamente.
4. Escribe un mensaje de commit claro y descriptivo.
5. Envía un Pull Request explicando los cambios realizados.

## 4. Lista de verificación del Pull Request

Antes de enviar una contribución, verifica lo siguiente:

* [ ] El código sigue una estructura clara y ordenada.
* [ ] Los cambios fueron probados.
* [ ] No se introdujeron errores nuevos.
* [ ] La documentación fue actualizada cuando fue necesario.
* [ ] El Pull Request explica claramente su propósito.

## 5. Buenas prácticas

* Mantener un código legible y organizado.
* Utilizar nombres descriptivos para variables y funciones.
* Evitar cambios que no estén relacionados con la contribución.
* Mantener actualizada la documentación del proyecto.

¡Gracias por contribuir a Tienda TECSUP!
